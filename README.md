# 学院派系统造型教学训练营班

获课：jzit.top/26846/

**一、班级定位：把 "会画" 拆成可训练的能力**

造型训练最常见的误区，是把 "画得像" 当成唯一目标。学员临摹了一张石膏像，看起来很接近，换一个角度、换一个对象却无从下手。学院派体系的价值不在风格，而在于它把造型这件事拆成一组彼此独立、可单独训练、又可组合的能力模块。训练营的功能定位因此明确：让学员在每一个模块上都具备可复现的判断与动作，而不是依赖运气和手感。

**二、观察功能：从 "看对象" 到 "看关系"**

造型的第一项功能是观察。学院派强调的观察，核心是提取结构关系，而非盯着轮廓：哪里是最高点、哪里最低、中轴线如何倾斜、各体块之间怎样咬合。训练营通常用一套固定动作来建立这个习惯：先定大形位置，再找比例分割，最后才进入细节。观察功能训练到位，学员面对陌生对象时不会停在 "不知道怎么下笔" 这一步。

**三、比例与结构功能：让形体站得住**

第二项功能是比例与结构。比例解决 "各部分多大、在哪"，结构解决 "这些东西怎么连起来、受力在哪里"。课程会用几何体归纳的方式，把复杂对象压成基本体块的组合，并通过辅助线、中心线、透视线来校验。功能上它追求两个结果：形不塌，位置不漂移。这是所有后续表现能力的地基，地基不稳，后面的明暗和质感都是在错误上叠加。

**四、体积与空间功能：从平面符号到立体感**

第三项功能是体积与空间。很多初学者的画 "平"，问题出在他们把对象当成二维图案在描。训练营的对应手段是建立 "体块优先" 的意识：任何复杂形都先问它由哪几个几何体构成、它们的朝向、前后遮挡关系。配套训练通常是同一组静物的多角度速写、切面练习、以及把虚实和遮挡关系明确画出来。功能目标是：观者不看细节也能感到这个物体有厚度、有前后。

**五、光影与质感功能：用有限层次建立可信度**

第四项功能是光影与材质。这部分训练的关键是建立一套可控的明度秩序：受光、背光、明暗交界、反光、投影各自承担什么角色，什么地方该压、什么地方该提。质感则是对不同材料反射特性的区分。训练营会强调一个反直觉的原则：光影服务于结构，而不是覆盖结构。层次过多、到处提亮，画面会碎；层次节制、该黑的地方敢黑，形体反而立起来。

**六、构图与画面组织功能**

第五项功能是构图。单体造型过关之后，画面组织能力开始决定作品的上限：主体位置、视觉重心、疏密节奏、留白的呼吸感、边缘的收放。学院派训练常通过大量小稿快速试排，用低成本的方式筛掉差的方案，再进入正稿。功能上它解决的是 "这张画第一眼把人引到哪里"，这属于决策问题，与技法问题不同。

**七、迁移与表达功能：从训练场走向创作**

第六项功能是迁移。训练营的真正交付物，是学员能把课堂上的方法用到陌生题材上：人物、场景、设计草图、商业稿。评价标准也随之改变：不再看 "像不像范画"，而看 "面对新对象时，能否在三十分钟内建立起可信的结构与秩序"。这一步通常是入门与专业的分界线。

**八、反馈与训练机制功能**

作为 "训练营" 而非 "课程"，其核心功能还包括反馈机制：高频的小任务、明确的单点评价标准、逐张批改与横向对比、以及可量化的进步记录。学员最需要的是一句 "你这次错在比例还是错在明度"，而非笼统的 "再练练"。学院派之所以有效，很大程度上靠的是这种可拆解、可指认的反馈密度。
